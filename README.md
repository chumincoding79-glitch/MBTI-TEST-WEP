# 🧭 MBTI Personality Test (MBTI 성향 분석 테스트)

모바일과 데스크톱 모두에 최적화된 인터랙티브 MBTI 테스트 웹 애플리케이션입니다.  
20문항 간편 모드와 40문항 정밀 모드를 지원하며, 4대 지표별 비율 막대 그래프 및 **6개 축 성향 레이더 차트**를 통해 자신의 성향 밸런스를 시각적으로 확인할 수 있습니다.

---

## ✨ 주요 기능

1. **2가지 검사 모드 지원**
   - ⚡ **간편하게 하기 (20문항)**: 각 지표별 핵심 5문항씩 빠르게 압축하여 약 2분 만에 완료
   - 🎯 **정확하게 하기 (40문항)**: 40개 전체 문항을 바탕으로 정밀한 성향 진단 (약 5분 소요)

2. **직관적인 문항 진행 UX**
   - 현재 모드별 실시간 진행률 바 및 문항 번호 표기
   - 5점 척도 선택 즉시 0.25초 후 자동 다음 문항 이동 (이전 질문 되돌아가기 지원)

3. **1.5초 두근거림 결과 공개 연출**
   - 마지막 문항 완료 후, 화면 중앙에 `"나의 MBTI는??"` 문구와 함께 하트비트 애니메이션 연출 후 결과 전환

4. **풍부한 결과 분석 화면**
   - 최종 4글자 MBTI 유형 및 대표 칭호, 해시태그, 상세 특징 설명
   - 4대 지표(E/I, S/N, T/F, J/P) 비율 게이지 막대 그래프
   - **성향 레이더 차트**: 외향성(E), 직관력(N), 논리력(T), 계획성(J), 공감력(F), 현실감각(S)의 6개 능력치 밸런스를 SVG로 시각화
   - 결과 공유(링크 복사) 및 다시 테스트하기 기능

5. **다크 모드 / 라이트 모드 지원**
   - 우측 상단 해/달 토글 버튼을 통한 부드러운 테마 전환 (`localStorage` 저장 지원)
